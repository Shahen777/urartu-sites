# Дизайн-спека: серия ресторанных сайтов Urartu (флагманское качество)

Дата: 2026-07-09 · Статус: утверждено господином Шагеном (пилот «все три сразу»)

## Цель

Расширить портфель Urartu с отелей на рестораны. Три сайта-витрины флагманского
уровня — каждый со **своей айдентикой** (не общий шаблон), дизайн заметно выше
отельной серии: современный, необычный, «студийный». Использование прежнее:
живое демо для холодного питча владельцу + персональное КП (КП — отдельный шаг
после приёмки сайтов).

## Планка дизайна (обязательна для всех трёх)

Чем серия отличается от отельного шаблона:

- **Журнальная типографика**: заголовки-манифесты на весь экран, контрастная пара
  дисплейный+гротеск, у каждого ресторана своя пара шрифтов (Google Fonts,
  поддержка кириллицы обязательна).
- **Скролл-хореография**: parallax, reveal фото из маски, счётчики, секции
  въезжают каскадом (IntersectionObserver, prefers-reduced-motion учитывается).
- **Горизонтальная лента меню** с drag-скроллом вместо сетки.
- **Живые детали**: шумовая текстура фона, кастомный курсор с инверсией на фото
  (только desktop), hover-эффекты на блюдах.
- **Sticky-бронирование**: кнопка брони всегда доступна (звонок + WhatsApp/TG).
- Чистый HTML/CSS/JS, самодостаточный CSS (без CDN-фреймворков), один каталог
  на сайт в `~/Projects/urartu-sites/<slug>/`, деплой на GitHub Pages.
- Мобильная версия равноценна десктопной (проверка скриншотами 390px).

## Структура каждого сайта

5 страниц: `index` (герой с видео/анимацией, манифест, хиты, атмосфера, отзывы,
бронь) · `menu` · `about` · `gallery` · `contacts` (карта, телефоны, бронь).

## Контент-пайплайн (как в отельной серии, с поправками)

1. РЕАЛЬНЫЕ фото прежде всего: Яндекс.Карты gallery-harvest (скролл-коллект
   XXXL), для Rony Oyster дополнительно инста-эстетика. Проверять, что фото
   именно этого заведения.
2. kie.ai nano-banana (Grok сейчас не работает): премиум-обработка фото через
   `KieClient.generate_image_edit` (model google/nano-banana-edit, ~$0.02/кадр,
   ключ в ~/Projects/content-factory/.env) — можно передавать XXXL-URL
   Яндекс.Карт напрямую. Убирать чужие водяные знаки, без текста/логотипов.
   Оптимизация: `sips -s format jpeg -Z 1200 ... formatOptions 82`.
   Hero-видео: решить на месте (Veo через kie.ai платный) — по умолчанию
   премиум CSS-анимация героя вместо видео.
3. Меню и факты — из отзывов/агрегаторов (2ГИС, Яндекс, TripAdvisor);
   цены не выдумывать: писать «уточняйте» или диапазон из отзывов.
4. Контакты на сайтах — реальные телефоны заведений (из базы лидов), формы
   брони ведут на телефон/WhatsApp владельца.

## Известные грабли (перенос из отельной серии)

- Scrim поверх hero-медиа: z-index скрима ≥ медиа, текст выше.
- `.gitignore` исключает `img/orig/` — постеры указывают на закоммиченный jpg.
- QA каждой страницы скриншотом live-URL после деплоя (CDN может отдавать
  старый CSS 1–2 мин).
- macOS bash 3.2 — без `declare -A`.

## Критерий приёмки

Все три сайта живые на `https://shahen777.github.io/urartu-sites/<slug>/`,
господин Шаген смотрит и подтверждает уровень. После приёмки — отдельным шагом
персональные КП по образцу отельных.

## Вне скоупа

Персональные КП, рассылка, новые ниши (свадебные площадки, СПА) — после
приёмки этой тройки.
