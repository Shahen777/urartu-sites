# Style: MERCURY (refero.design) — для медцентра «Здоровье»

Тема: «альпийский банкинг» — near-black холст #171721, кинематографично, «обсерватория»; карточки-графит чуть светлее плавают. Монохром: ivory-текст на onyx, кобальт #5266eb — ЕДИНСТВЕННЫЙ акцент, только для primary-действий. Плоские безрамочные компоненты, разделение value-контрастом, БЕЗ теней.

## Цвета
- Onyx Canvas #171721 — фон страницы/секций/футер
- Graphite Card #1e1e2a — карточки/секции (на шаг светлее)
- Obsidian Button #272735 — вторичные кнопки, инлайн-формы
- Slate Border #70707d — делители/границы
- Mist Border #e2e3ed — тонкие hairline, ghost-кнопки, края инпутов
- Ash Text #c3c3cc — приглушённый текст/подписи
- Ivory Text #ededf3 — основной текст/иконки/нав (НЕ #fff для текста!)
- Cobalt #5266eb — filled-кнопки, выбранная навигация (единственный chromatic, один primary/стр)
- Pure White #fff — текст/иконки на кобальтовых кнопках

## Типографика
- Body 'Arcadia' → замена 'Inter' (кириллица), веса 360/400/420/480. body 16/1.5.
- Display 'Arcadia Display' → 'Inter' (или 'Manrope') вес 480, «широкий, архитектурный», трекинг положительный на крупном (0.01em@42). display 65/1.1/480, heading-lg 42/480, heading 32/480.
- caption 12, body-sm 14, subheading 21, body-lg 18.

## Радиусы/отступы/тени
- Радиусы: карточки 12px, кнопки/инпуты 32px (пилюли), nav/теги 40px, default 4px. НЕ острые углы (0-4px) на кнопках/инпутах/нав.
- Base 4px, density SPACIOUS; scale 4..128; section gap 72px; card padding 32px; max-width 1200px.
- ТЕНЕЙ НЕТ. Elevation = value-контраст: graphite #1e1e2a на шаг светлее onyx #171721.

## Компоненты
- Primary CTA (Cobalt): bg #5266eb, белый текст 16/400, radius 32px (пилюля), без границы/тени. Один primary/стр. Кобальты не рядом без gap 32px.
- Ghost Outline: прозрачный, border 1px #ededf3, ivory-текст 16/400, radius 40px.
- Graphite Card: #1e1e2a, 12px, padding 32, без тени/границы.
- Hero: 100vw×~100vh, full-bleed фото с тёмным overlay, headline 65/480, subtext 18/480, контент max-width ~640 центр.
- Nav: full-width, прозрачный/frosted-glass (backdrop-blur), бренд слева, ссылки центр, «Войти»+primary справа.
- Section: dark canvas, контент 1200px, 72px верт-паддинг.

## Do / Don't
- Do: кобальт только 1 primary/стр; карточки #1e1e2a 12px 32px; display вес 480; пилюли 32/40; body 16/400 1.5; ритм 72px; ghost #ededf3.
- Don't: несколько ярких акцентов; тени; bold 700+ заголовки; острые углы на кнопках/инпутах/нав; #fff для body-текста (только #ededf3); кобальты вплотную; яркие/насыщенные фоны секций.

Иконки — минимальные линии ivory.
