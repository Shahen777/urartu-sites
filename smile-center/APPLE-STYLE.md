# Apple Style Reference (для сборки Смайл Центр)

Тема: light. Near-white канвас, воздух, ОДИН синий акцент только на кнопках. Типографика — главный голос (SF Pro / Inter, отрицательный трекинг). Продукт = дизайн: крупные фото во всю ширину, chrome прячется в хайрлайны и ghost-навигацию. Секции чередуют #f5f5f7 и цветные washes. Ритм — за счёт масштаба, не декора.

## Цвета
- --color-apple-blue #0071e3 — ТОЛЬКО заливка кнопок и selected. Один цвет — одна задача. НИКОГДА для текста/границ/декора.
- --color-link-blue #0066cc — граница outlined-кнопок, инлайн-ссылки.
- --color-signal-blue #2997ff — ТОЛЬКО декоративный акцент (курсивный вариант слова, тонкие штрихи). Не интерактив.
- --color-carbon #1d1d1f — основной текст, границы заголовков, hairline-правила.
- --color-frost #f5f5f7 — канвас страницы/секций (surface 0).
- --color-ice #f4f8fb — приподнятый wash (surface 1, для featured-секций).
- --color-smoke #333 / --graphite #474747 / --ash #707070 / --mist #858585 — серые для границ/иконок/приглушённого текста.
- --color-pebble #e2e2e5 — заливка кнопок-нейтралов/disabled.
- border hairline: #d2d2d7 (светлые) или #333 (тёмные секции).

## Типографика (Inter как замена SF Pro; подключить Google Fonts, кириллица)
- Display (40px+): weight 600 (макс для заголовков-названий; 700 только для промо-локапов), tracking слегка положительный на 40px+ (0.011em).
- Text/Body: 17px weight 400, letter-spacing -0.016em (это и есть «эппловская точность»). Subheads/дескрипторы — weight 300 (шёпот-голос). Nav/кнопки — weight 600.
- Шкала: caption 12/-0.264px, body-sm 14, body 17/-0.272px, subheading 21, heading-sm 28, heading 40, heading-lg 44, display 56/0.616px.
- line-height body 1.47; заголовки 1.07–1.19.

## Формы и радиусы
- Кнопки/пилюли/теги: radius 980px (ВСЕГДА круглые). Карточки/изображения/инпуты: radius 8px. Других радиусов нет.
- Base spacing 4px; шкала 4/8/12/16/20/24/40/48/56. Section gap 64px+. Card padding 24px. Element gap 12px.
- page: full-bleed, без фикс-контейнера; текст центрируется внутри ~980px. max-width 1440.

## Тени/глубина
- НЕТ теней на карточках/кнопках/нав. Иерархия — сдвиг поверхности (#f5f5f7 → #f4f8fb → #e2e2e5) + hairline 1px. Единственная тень — на ФОТО-продукте: rgba(0,0,0,.22) 3px 5px 30px, чтобы «приземлить» на белом. Плоскость — подпись стиля.

## Компоненты
- Filled Pill Button: radius 980, bg #0071e3, text #f4f8fb 17px/400, padding 11px 15px, без границы и тени. Единственный залитый интерактив.
- Outlined Pill Button: radius 980, border 1px #0066cc, text #0066cc 17/400, прозрачный фон. Пара к filled. НИКОГДА две filled рядом.
- Ghost Link: без фона/границы, text #0066cc, underline на hover.
- Global Nav: full-width, белый (или #1d1d1f), padding 8px верт, ссылки 12px/400 carbon, лого слева, категории по центру, иконки справа, hairline снизу.
- Product Hero: bg #f5f5f7, по ЦЕНТРУ имя 56px/600 carbon, tagline 26px/300, две пилюли по центру, крупный рендер продукта заполняет секцию с большим нижним отступом.
- Feature Banner: full-width фото/цвет-wash, overlay-текст и CTA. Фото ЕСТЬ поверхность (без карточки). Тёмный с белым текстом или пастель-wash с тёмным.
- Service Card Grid: ряд/грид карточек, каждая — full-bleed фото, radius 8, белый текст поверх, заголовок 24-28/600, лейбл 12-14, пилюля снизу.
- Typography-only CTA: центр: имя 40-56/600, дескриптор 21/300, опц. курсивный вариант 28px #2997ff, две пилюли, много воздуха.
- Footer: #f5f5f7, мультиколоночный грид ссылок 12/400 ash, hairline #d2d2d7, мелкий шрифт.
- Form Input: radius 8, border 1px #d2d2d7, 14-17px, fill #f5f5f7, focus-ring #0071e3 2px.

## Do
- #0071e3 только для filled-кнопок и активных состояний.
- Каждую filled-синюю пару с outlined-синей вторичной; не стакать две filled.
- Body 17px с tracking -0.016em.
- Фото во всю ширину вьюпорта; не зажимать hero в контейнер.
- 980px для всех кнопок/тегов/пилюль.
- Секции full-bleed #f5f5f7 или один product-wash; без карточек-контейнеров внутри секции.
- Weight 300 для субхедов/дескрипторов (эппловский шёпот); 400 body; 600 nav.

## Don't
- #0071e3 НЕ для текста/границ/декора.
- НЕТ теней на карточках/кнопках/нав.
- НЕ 700 для имён-заголовков (макс 600).
- НЕ карточка/панель внутри #f5f5f7-секции (канвас сам — поверхность).
- НЕ узкая колонка для основного контента.
- НЕ радиусы кроме 980 (кнопки) и 8 (карточки/фото).
- НЕ смешивать три синих в одном элементе.
